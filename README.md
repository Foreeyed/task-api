# Task API

HTTP API для управления длительными I/O bound задачами.

## Запуск

1. Убедитесь, что у вас установлен Go (версия 1.16 или выше)
2. Клонируйте репозиторий: git clone https://github.com/Foreeyed/task-api
3. Перейдите в директорию проекта: cd task-api
4. Выполните команду: go run cmd/server/main.go
